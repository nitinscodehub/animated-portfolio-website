# Animated Portfolio Website

Welcome to my Animated Portfolio Website! 🎉  
This is a fully responsive personal portfolio built with HTML, CSS, and JavaScript to showcase my skills, projects, and contact information.

👉 Live Demo: [https://nitinssportfolio.netlify.app/](https://nitinssportfolio.netlify.app/)

---

## 🧠 About the Project

This portfolio is designed to highlight my work, skills, and achievements in a clean and modern layout.  
It includes animated sections, smooth scroll navigation, and interactive UI elements for a better user experience.
